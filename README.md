### Soal 5

**Jawaban:**

- **text**: Teks yang akan ditampilkan.  
- **style**: Gaya visual teks (warna, ketebalan, dll).  
- **minFontSize**: Ukuran font terkecil yang diizinkan.  
- **maxFontSize**: Ukuran font terbesar yang diizinkan.  
- **stepGranularity**: Interval perubahan ukuran font saat menyesuaikan diri.  
- **presetFontSizes**: Daftar ukuran font spesifik yang boleh digunakan.  
- **maxLines**: Jumlah baris maksimal untuk teks.  
- **overflow**: Aksi jika teks meluap (misal: ...).  
- **overflowReplacement**: Widget pengganti jika teks meluap.  
- **group**: Menyeragamkan ukuran font di beberapa AutoSizeText berbeda.  
- **textAlign**: Perataan teks horizontal (kiri, tengah, kanan).  
- **wrapWords**: Memastikan teks terpotong per kata, bukan per karakter.
